# 🎮 GPU Arena

موقع تفاعلي لاستعراض ومقارنة كروت الشاشة (Graphics Cards / GPUs) بتصميم عصري Dark Mode.

## المميزات
- اختيار الشركة المصنعة (NVIDIA / AMD / Intel) ثم اختيار الموديل
- بطاقة تفاعلية: VRAM، المعمارية، الأنوية، الترددات، TDP، PSU، Ray Tracing، DLSS/FSR، PCIe
- تقدير الأداء في الألعاب (1080p / 1440p / 4K)
- مقارنة كرتين جنباً إلى جنب مع إبراز الأفضل باللون الأخضر
- 39 كرتاً (حديثة، قديمة، متوسطة، رائدة، اقتصادية)

## التشغيل
افتح ملف `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
1. ارفع الملفات الثلاثة (`index.html`, `style.css`, `app.js`) إلى مستودع
2. Settings → Pages → اختر الفرع `main` → Save
